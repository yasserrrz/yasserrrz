### 🧩 How I build

I try to keep my frontend work:

- **Simple** — avoid unnecessary abstractions.
- **Reusable** — build components around real reusable patterns.
- **Maintainable** — optimize for the developer reading the code next.
- **Type-safe** — TypeScript should help the architecture, not fight it.
- **Design-system driven** — consistent components, tokens, and behaviors.
- **Performance-aware** — especially when working with Next.js.
- **Accessible & responsive** — UI should work beyond the happy path.

I generally follow **KISS, SOLID, separation of concerns, and composition over duplication** while avoiding over-engineering.
